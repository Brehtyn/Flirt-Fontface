# Flirt Fontface

Floriana Hanna was a beautiful individual. Her personable attitude earned the nickname Flirt early in her jovial life; it fit til the end. We miss Floriana dearly and try to perserve her legacy, including her unique handwriting. May this be a cherished keepsafe for those who knew her and a free stylish fontface for those who did not.

## Installation

#### Windows OS
1. Right clicked the Zipped file and extract it to a folder on your desktop. Ignore this step if you downloaded the files directly.
2. Find the Typeface.tff file.
3. Right click the file. 
4. Click the 'Install' option.


#### Mac OS

1. Right clicked the Zipped file and extract it to a folder on your desktop. Ignore this step if you downloaded the files directly.
2. Find the Typeface Mac.ttf file.
3. Open the Fontbook Application.
4. Choose File > Add Fonts to Current User. 
5. Drag the font file to the Font Book app icon in the Dock
6. Click the 'Install' option.

#### Linux Distrubtions
You can figure it out.

## Contributing

This project was made with [Birdfont](https://birdfont.org/) opensource software, but can theoretically be edited with any font-making software. Feel free to to do so.

For Birdfont, open the flirt.birdfont file. Edit as desired. Test by exporting it via
```bash
  Menu > Import and Export > Export Fonts
```
Install the generated font (refer to above if needed) and check it in any appropriate software, such as Microsoft word. If improved, save the edits via
```bash
  Menu > File > Save
```
Email me if you need me to commit your changes to git.
